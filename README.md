# Cut the Save

**简体中文** | [English overview](README.en.md)

Cut the Save 是 Steam 版 *Cut the Rope* 的存档检查、编辑和高刷新率辅助工具，支持简体中文、繁體中文和 English。

当前为待验收的开发候选；包校验、隔离测试和真实设备验收分别记录，构建成功不代表正式发布。更新信任和官方 RTSS 安装包元数据尚未配置。
### 快速使用

从 [GitHub 预发布页面](https://github.com/tianqistudio/cut-the-save/releases/tag/v1.0.1-preview.20261013)下载安装包及 SHA-256 校验文件。Windows x64 安装版内置运行时，桌面和开始菜单快捷方式可分别选择；使用与构建步骤见[安装说明](docs/installer.md)。当前安装包未签名，尚未完成真实机器上的安装、升级和卸载验收。

1. 启动程序后选择语言。程序会读取 Windows 界面语言给出推荐，也可以在右上角随时切换。
2. 启动后程序会先进行一次只读检测；也可以点击「自动检测」。如果找不到存档，再点击「打开存档」手动选择 `ctr_save.bin`。
   手动打开成功后，该位置会保存为下一次优先检测位置。
3. 检测到 `CutTheRopeApp.exe` 后，「通过 Steam 启动游戏」按钮会启用。它只调用 Steam 的 AppID `223280`，不会修改存档或 RTSS 设置。
4. 在右侧检查条目和校验状态，再按需要执行批量操作。
5. 点击「另存为」保存修改。原始文件不会被自动覆盖，程序会在写入前后验证并创建备份。
6. 点击「备份」查看当前存档的历史快照；恢复前程序会先备份当前文件。

两个编辑视图会同步已确认的值，批量操作不会丢弃先前的手动编辑。离开未保存的编辑前会提示确认；保存和恢复前需关闭游戏。

有错误、重复键等未确认警告或无法识别进度字段的文件只读；无效编码、异常长度或未知尾部会停止打开，不会自动修补。覆盖会比对打开/确认时的文件版本，检测到外部变化则停止并保留编辑。写入异常会明确提示已恢复、当前文件保留或需人工检查，并列出恢复文件；请勿直接重试覆盖。

### 备份管理

仓库提供两组[存档示例](samples/README.md)，包含原始与编辑后副本及 SHA-256 校验清单，可用于检查解析、编辑差异和另存为流程。

「备份」会显示打开时、覆盖写入前和恢复前的已登记快照，包括大小、来源和 SHA-256；可锁定重要备份、复制校验值或打开所在文件夹。

打开、保存或恢复成功后，程序会维护备份目录的全局保留目标：最多 50 份、200 MiB（界面简写为 200 MB）。锁定、正在使用、每份存档最新、旧版或来源不明的备份不会被自动清理，因此可能超过目标。手动「清理过期备份」先显示数量并询问确认；旧版未登记文件不会按文件名猜测归属或导入。检测不会改写游戏存档，但成功打开会创建快照并执行上述备份维护。

清理中断后，「备份 → 修复备份记录」可经确认恢复一致状态，不会修改游戏存档。冲突会停止处理并保留文件；请勿删除恢复记录或反复覆盖。

保存中断后，进入「备份 → 处理中断保存」。可保留当前状态，或在游戏关闭且文件仍为已验证结果时恢复写入前内容；旧备份会锁定，恢复前也会备份当前结果。处理记录和未知残留保留，启动时不会自动覆盖存档。

### 外观

语言也可直接改 INI：[General] 段使用 Language=zh-CN、Language=zh-TW 或 Language=en-US，关闭程序后修改，重启生效；兼容 zhcn、zhtw、usen。无需操作语言选择器。

右上角「外观」可选择 **Windows 11（默认）** 或 **经典（原界面）**，并独立选择「跟随系统 / 浅色 / 深色」。点击「应用」后立即生效；「取消」保留当前设置。跟随系统模式会响应 Windows 的应用颜色变化，无需重启。

偏好与语言一起保存在 `%LOCALAPPDATA%\CutTheSave\CutTheSave.ini`，对应 `Theme=Windows11|Classic` 和 `ColorMode=System|Light|Dark`。切换语言会保留外观及已记住的存档位置。外观切换不会写入游戏存档或 RTSS Profile。

### 速度修复

「RTSS 获取引导」提供三语安装说明和版本检查。未知版本或文件哈希不符时停止自动 Profile 操作，并保留原设置与恢复记录；这不影响存档编辑。当前内置安装包元数据尚未核验，因此只提供官方页面入口，不自动下载或安装。详见 [RTSS 安全边界](docs/rtss-safety.md)。

程序会先读取主屏幕刷新率。屏幕为 `60 Hz` 时无需 RTSS 限制；高于 `60 Hz` 时，才建议检测 RTSS，并只为 `CutTheRopeApp.exe` 设置 `60 FPS`。应用和撤销时，Windows 会只为这一次 RTSS Profile 操作请求管理员权限；程序仍以普通权限运行。写入前会备份，写入后必须回读 `60/1`，必要时会启动 RTSS，未发生外部改动且记录完整时可以撤销。旧版记录、写入中断或 Profile 被再次修改时会保留证据并停止自动撤销，请勿删除备份和修复记录。

### 支持包

如果需要请别人协助排查，可以点击程序右上角的「支持包」。它会生成一个脱敏 ZIP，包含版本、系统、配置状态以及 Steam / RTSS 检测摘要；默认不包含 `ctr_save.bin`，也不会上传任何内容。

### 更新

当前开发版未配置正式签名公钥和发布地址，因此更新保持离线。发布者必须在源码中固定公钥、标识、频道、HTTPS 主机和两个独立来源后重新构建；程序旁的 `CutTheSave.update.ini` 仅控制 `[Update] Enabled=true|false`，不能更换这些信任信息。见 [更新配置](UPDATE_CONFIGURATION.md)。

已配置的发行版可在启动后后台检查，成功且无冲突的检查最多每 24 小时一次。一个来源失败仍检查另一个；签名或版本冲突不会安装，两个来源都不可用不影响存档编辑。下载并安装前询问确认，默认选择「否」。


## 构建与验证

需要 Windows x64、.NET 10 SDK 和 PowerShell 7。从项目根目录运行：

```powershell
pwsh -File scripts/Publish-CutTheSave.ps1 -RunUpdaterAcceptance
```

默认版本来自 `Directory.Build.props`；可用 `-ReleaseVersion 1.0.1` 显式指定三段版本。脚本构建隔离测试、发布便携程序，并生成 ZIP、完整 SHA-256 清单与包验证回执。`release-metadata.json` 的版本必须与包内程序集一致。仓库提供已核对的存档示例，不包含用户工作存档、用户 INI、发布索引和维护者现场回执。

更新器验收使用临时签名密钥与合成文件测试事务；正式程序保持固定信任，未配置时不会安装更新。此验收不代表生产更新链已经启用。

复核交付包只需 ZIP 和相邻校验清单，不再依赖原构建目录：

```powershell
pwsh -File scripts/Verify-CutTheSaveRelease.ps1 -Zip <候选.zip> -Checksums <候选-SHA256.txt>
```

界面在较小工作区折行工具栏并压缩摘要；检测、打开、保存和保留维护期间会显示忙碌状态，暂时阻止重复操作和关闭。未保存修改持续显示在当前文件区域，切换语言不会重建草稿。

完整三语说明见 [使用指南](docs/guide.md)，现场验收要求见 [FIELD_ACCEPTANCE.md](FIELD_ACCEPTANCE.md)。
